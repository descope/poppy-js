# Security policy

## Reporting a vulnerability

Do not open a public issue. Report it privately through GitHub: on this repository's **Security** tab, choose **Report a vulnerability**.

Include the affected version, what an attacker can do, and the steps to reproduce. We aim to acknowledge reports within three business days and will keep you updated until a fix is released.

## Supported versions

Only the latest release receives security fixes while the package is below 1.0.

## Scope

In scope: this SDK's handling of tokens, keys, DPoP proofs, discovery checks and the hosts it sends credentials to.

Out of scope: vulnerabilities in a Company's authorization server or APIs, which belong to that Company, and issues in the Personal Agent Protocol specification itself, which belong to the specification's maintainers.
